Nano-Commons node console

This page controls your own node or testbed, running on your machine. There is no central Nano-Commons server. State lives in this process's memory only.

The operator token controls this console only. Do not offer this console to others as a public service.

Missions

For testing only: a hosted mission lets this console sign tasks for you, so its key sits in this process's memory. For a real mission, keep the key on your own machine: create it with nano-commons keygen and send signed work with nano-commons submit.

Workers

Canary

Testbed verifier. A canary is a task whose right answer you already know. Workers are scored against it, and it can raise an alarm. It uses the mission and workers selected above. On a real network, canaries come from independent verifiers, never from a single console.

Checkpoints

unverified: no canary has tested its workers. vouched: its workers passed a canary. tainted: they failed one. reviewed: an operator accepted it.
